# 汴京一日

一座沿汴河展开的北宋汴京三维街景。本项目以《清明上河图》为灵感通过JavaScript还原了宋代都城市井风貌。在场景中，您可以从城郊一路走到码头、虹桥、街市、酒楼和城门。您可以：
- 沿着汴河漫步，观赏两岸风光；
- 登上城楼俯瞰街巷；
- 穿梭于城内街道，感受坊巷人家。

场景内不仅有静态的建筑复原，还有商贩、行人、骑者、船只和巡卒在持续活动，为您呈现一个鲜活的宋朝都城。

## 本地运行

```powershell
npm install
npm run build
npx serve dist
```

然后打开终端显示的本地地址。浏览器需要支持 WebGL。

## 操作

- 桌面：W/A/S/D 行走，鼠标拖动视角；也可以点击画面启用鼠标视角。
- 手机或平板：屏幕左侧摇杆移动，拖动场景转动视角。
- 使用场景中的地点按钮切换到地标，也可以沿预设路线自动漫游。
- 右上角可以调整白昼时辰、开启环境音或全屏浏览。

## 技术

Three.js、原生 JavaScript、esbuild。`src/` 保存场景与交互代码；`dist/` 是可直接托管的静态网站文件。
